# Mutation baseline for cerulion_remoted: the pure decisions of the e-stop policy and of the stop.
#
# Scope: two pure scopes, the e-stop policy file below and the stop's
# exit-status and deadline decisions in the second section. The rest of the
# crate holds the lease, transport and file paths that the mutation rule does
# not cover.
#
# Run:     cargo mutants -p cerulion_remoted \
#            -f crates/cerulion_remoted/src/estop_policy.rs -- --lib
# Result:  4 mutants: 1 caught, 3 unviable (do not compile), 0 missed.
#
# restart_check: cargo-mutants replaces its body with `Default::default()`,
# which does not compile because `RestartCheck` has no default. Its match has
# no `_ =>` arm, so no arm is deleted; the four (step, holds) cells are
# asserted exactly by
# `estop_policy::tests::restart_runs_each_step_while_the_estop_does_not_hold`
# and `estop_policy::tests::restart_is_refused_at_the_step_the_estop_holds_at`,
# so changing what any arm returns fails one of them.
#
# after_answer: `==` replaced with `!=` is caught (by
# `estop_policy::tests::a_delivery_ends_once_no_engage_arrived_during_its_answered_attempt`
# among others). Its body replaced with `Default::default()` does not compile:
# `AfterAnswer` has no default.
#
# estop_head_bound: its body replaced with `Default::default()` does not
# compile, because `flag` and `OPS_ESTOP_HEAD_FLOOR` are then unused and the
# crate denies unused variables and dead code. A body that returns the smaller
# of the two values instead fails
# `estop_policy::tests::the_estop_head_bound_is_at_least_one_second`.
#
# Every mutant that survives the test suite is listed below with the reason it
# is not killed. A survivor that is not listed here is a gap in the tests: kill
# it with a test, or list it here with a reason.
