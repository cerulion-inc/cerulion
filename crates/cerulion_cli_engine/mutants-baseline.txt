# Mutation baseline for cerulion_cli_engine: the delivery flag token of
# `cerulion ros2 run` and `ros2 launch`, and the decisions the recorder and a
# resumed replay make about a node a checkpoint states as stopped.
#
# Scope: `delivery_flag_token` in src/ros2_cmd.rs, which reads a forwarded
# argument as `--record-deliveries` or `--replay-deliveries`, alone or with an
# inline `=value`, matched on bytes so a value that is not UTF-8 is kept whole.
# The rest of the file stages the child environment and execs `ros2`, which the
# mutation rule does not cover.
#
# Run:     cargo mutants -p cerulion_cli_engine \
#            -f crates/cerulion_cli_engine/src/ros2_cmd.rs \
#            --re 'delivery_flag_token' --exclude-re 'tests::' \
#            --timeout 300 --cap-lints true -- \
#            --test ros2_delivery_flags_test --test ros2_cmd_test
#          (run in place in a scratch checkout; the unmutated baseline passed)
# Lints:   --cap-lints true, so a body replacement that leaves a parameter
#          unused still compiles and meets the tests.
# Result:  5 mutants: 5 caught, 0 unviable, 0 missed. Each replaces the
#          body with None or a Some of an empty or made-up flag name, with and
#          without a value. The tool generates no mutant inside the match on
#          the bytes after the flag: it has no bare `_` arm to delete.
#

# Second scope: the decisions the recorder and a resumed replay make about a
# node a checkpoint states as stopped.
#
# Scope: the pure decision functions on the lines the anchor stop change added
# or changed. In src/replay_engine.rs: the recorder's trace format stamp and
# the reader's gate on it (`stamp_trace_format`,
# `recorder_states_anchor_stops`, `recorder_states_anchor_stops_at`), the
# stops the anchor states (`AnchorStops`, `resolve_anchor_stops`), the
# refusals when the runtime declines a stop restore (`stop_restore_failure`)
# or the recording fires a stopped node (`stopped_fire_refusal`), and the
# topics the replay re-executes (`reexecuted_topics`). In
# src/replay_rederive.rs: the pass's restore and stops (`PassRestore`,
# `PassStops`, `StopPoint`, `is_stop_step_burst`), the pass entry that hands
# them to each rule (`verify`), the four rules that read them
# (`verify_period`, `verify_latest`, `verify_sync`, `verify_fifo`) and the
# text of a stand down (`StandDownReason::label`). Every other line of the two
# files is outside the change's diff, or, in replay_engine.rs, reads the bag
# or drives the scheduler, which the mutation rule does not cover.
#
# Run:     cargo mutants -p cerulion_cli_engine \
#            -f crates/cerulion_cli_engine/src/replay_engine.rs \
#            -f crates/cerulion_cli_engine/src/replay_rederive.rs \
#            --in-diff <the change's diff of the two files> \
#            --re 'stamp_trace_format|recorder_states_anchor_stops|reexecuted_topics|AnchorStops::|stop_restore_failure|resolve_anchor_stops|stopped_fire_refusal|PassRestore::|StopPoint::|PassStops::|is_stop_step_burst|verify_period|verify_latest|verify_sync|verify_fifo|\bverify\b|StandDownReason::label' \
#            --cap-lints true --in-place --timeout 600 \
