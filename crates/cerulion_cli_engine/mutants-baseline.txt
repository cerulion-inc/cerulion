# Mutation baseline for cerulion_cli_engine: the delivery flag token of
# `cerulion ros2 run` and `ros2 launch`, the decisions the recorder and a
# resumed replay make about a node a checkpoint states as stopped, the
# stand-downs a resumed replay applies to a node whose stop the recording
# does not state, and how a replay judges and re-executes a node that a
# `block` input in its own rank holds.
#
# Scope: `delivery_flag_token` in src/ros2_cmd.rs, which reads a forwarded
# argument as `--record-deliveries` or `--replay-deliveries`, alone or with an
# inline `=value`, matched on bytes so a value that is not UTF-8 is kept whole.
# The rest of the file stages the child environment and execs `ros2`, which the
# mutation rule does not cover.
#
# Run:     cargo mutants -p cerulion_cli_engine \
#            -f crates/cerulion_cli_engine/src/ros2_cmd.rs \
#            --re 'delivery_flag_token' --exclude-re 'tests::' \
#            --timeout 300 --cap-lints true -- \
#            --test ros2_delivery_flags_test --test ros2_cmd_test
#          (run in place in a scratch checkout; the unmutated baseline passed)
# Lints:   --cap-lints true, so a body replacement that leaves a parameter
#          unused still compiles and meets the tests.
# Result:  5 mutants: 5 caught, 0 unviable, 0 missed. Each replaces the
#          body with None or a Some of an empty or made-up flag name, with and
#          without a value. The tool generates no mutant inside the match on
#          the bytes after the flag: it has no bare `_` arm to delete.
#

# Second scope: the decisions the recorder and a resumed replay make about a
# node a checkpoint states as stopped.
#
# Scope: the pure decision functions on the lines the anchor stop change added
# or changed. In src/replay_engine.rs: the recorder's trace format stamp and

# stops the anchor states (`AnchorStops`, `resolve_anchor_stops`), the
