# Every mutant that survives the test suite is listed below with the reason it
# is not killed. A survivor that is not listed here is a gap in the tests: kill

replay_engine.rs: delete field channel from struct SidecarReading expression
in prepare_pass_verification
  Equivalent. The field is set only when no injected topic is listed in
  multi_publisher_topics, and with the field deleted the reading falls back to
  its default channel, Unreadable. Every reader of that reading in
  prepare_pass_verification (the label join, describe_label_reading and
  classify_label_reading) runs only for a topic in that empty set, so no
  output changes.
