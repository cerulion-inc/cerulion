# cerulion_cli_tui

An interactive terminal dashboard for
[Cerulion](https://github.com/cerulion-inc/cerulion), built with
[ratatui](https://ratatui.rs).

It shows the live graphs, nodes and topics on this machine. You reach it through
the CLI:

```bash
cargo install --locked cerulion_cli cerulion_netd
cerulion tui
```

See the [project README](https://github.com/cerulion-inc/cerulion#readme) for
an overview.
